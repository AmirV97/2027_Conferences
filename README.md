# AI, Medical AI & Critical Care Conference Calendar 2027

Interactive calendar of AI, machine learning, healthcare ML and critical-care conference deadlines and dates.

## Publish using GitHub Pages

1. Create a new public GitHub repository (for example `ai-medical-conference-calendar`).
2. Upload `index.html` to the repository root.
3. Go to **Settings → Pages → Build and deployment**.
4. Select **Deploy from a branch**, then **main**, **/(root)** and Save.
5. The website should appear at `https://YOUR-USERNAME.github.io/ai-medical-conference-calendar/` once deployed.

## Data caveat

This calendar contains estimated 2027 deadlines and dates derived from earlier conference editions. Check each conference's official page before relying on any deadline or making travel arrangements.

## Hosting dependencies

The HTML uses Plotly from its CDN and Merriweather from Google Fonts; an internet connection is required for these assets.
